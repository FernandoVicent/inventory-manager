## 🧾 Descrição das Versões

### 🔹 **Versão 1 (v1) — Estrutural / Procedural**
📅 Desenvolvida há alguns anos, esta foi minha primeira implementação do sistema de controle de estoque.

**Características principais:**
- Implementação **estrutural** (sem classes)
- Armazenamento de dados em **listas de dicionários**
- Geração de ID aleatória e verificação de duplicados
- Menu interativo simples no terminal
- CRUD básico (cadastrar, consultar, editar e excluir produtos)

> 💡 Esta versão foi fundamental para aprender lógica, estrutura de dados e organização de funções em Python.

---

### 🔸 **Versão 2 (v2) — Orientada a Objetos (POO)**
📅 Desenvolvida recentemente, esta versão é uma **refatoração completa** da v1, utilizando **boas práticas de POO** e **código modularizado**.

**Principais melhorias:**
- Estrutura orientada a objetos (`Product`, `Producer`, `Inventory`)
- **Geração automática de IDs** sem duplicação
- **Registro de logs** em arquivo (`logs.txt`)
- Código **organizado por módulos**
- **Validação de dados** e tratamento de erros
- Menu interativo aprimorado

> 🚀 A v2 representa um avanço técnico e conceitual, demonstrando domínio de abstração, encapsulamento e modularidade em Python.

---

## 🧩 Objetivo

Este repositório foi criado para documentar minha **evolução como desenvolvedor**, mostrando na prática:
- Como reestruturar um código procedural para POO  
- Como aplicar boas práticas de arquitetura  
- Como tornar o código mais escalável, reutilizável e fácil de manter  

---

## 🧠 Aprendizados

- Diferenças práticas entre **paradigma estrutural e orientado a objetos**  
- Importância da **modularização e separação de responsabilidades**  
- Uso de **logs** para auditoria e rastreabilidade  
- Evolução no uso de **boas práticas de desenvolvimento**
