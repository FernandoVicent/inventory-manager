# Sistemas de gerenciamento de estoque

## Regra de Negocios
 - Criar um sistema onde o usuário possa gerenciar seu estoque de produtos
    - verificar quantidade de produtos em estoque
    - CRUD
    - logs

## Clases

- Produtos 
    - id
    - nome
    - Fabricante
    - valor
    - qtd
  
- Fabricante
    - nome

## Funcionalidades

- Cadastrar produtos
- Remover Produtos
- Editar Produtos
- Pesquisar produtos por (id/nome/fabricante)
- Excluir produtos
- Verificar logs de alterações e updates
